## Offline reproduction

With Python 3.10 and the packages pinned in `requirements.txt`, run from this directory:

```bash
python -I -B scripts/reproduce.py --output /tmp/rev3-reproduction-new
```

Verify the generated bytes with:

```bash
python -I -B scripts/verify_reproduction.py --actual /tmp/rev3-reproduction-new
```

Choose a new output directory. This regenerates the tables, figures and scientific report from `inputs/`, without network access, models, inference, sensors or hardware SDKs. A stronger checked invocation rejects network, subprocess and historical source accesses:

```bash
python -I -B scripts/guarded_replay.py scripts/reproduce.py --output /tmp/rev3-guarded-new
```

The validation records distinguish compact public reproduction from the private restoration using only the canonical archive. `scripts/extract_canonical.py --base CANONICAL_ARCHIVE --output NEW_INPUTS` projects the exact private report generation; `ENTRYPOINTS.json` and the normal copy receipt bind those immutable bytes. Private raw captures, datasets, model artifacts, SDKs and original manuscripts are not part of this compact Git payload.

The legacy `analyze_energy.py` methods are reused in `legacy_energy_methods.py` for deterministic descriptive quantiles. Current identity selection and gates are recomputed by the new extractor and analysis. The old THESIS20 cohort is never silently combined with Revision 3.

Deterministic byte equality was checked with the pinned Python/package versions in [validation](validation/README.md). Other renderer/package versions may change figure bytes without changing numerical tables. `validation/REFERENCE_LIMITS.md` describes the unresolved provenance branches.
