# Manuscript asset packages

[MLSys](MLSys_assets.zip) contains the compact main-paper figure selection including the RegNet performance–energy/Pareto view; [Dissertation](Dissertation_assets.zip) contains all seven model trade-off/front views and their existing quality figures. Both include standalone LaTeX Tables 2/3, figures in PDF/SVG/PNG, captions, methods, exact plotted values in `figures/FIGURE_DATA.json`, `tables/PARETO_POINTS.csv`/`.json` and the claim-to-evidence table. Unpack and compile `preview.tex` with `pdflatex -halt-on-error -interaction=nonstopmode preview.tex`. Private manuscripts are not part of these packages.
