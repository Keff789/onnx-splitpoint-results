by `scripts/make_figures.py`. Source inputs are immutable; generated outputs
may be regenerated in place. References to PARMA concern the final v0.15.1
input selection, not the earlier TIM v0.1 displayed values.

`generated/numbers.tex` binds the primary Hailo interval, LLM, FP16 Q95 and pause
percentages used in prose to generated results. Other rounded text values can
be checked directly in the named tables. `paired_all_durations.csv` retains all
4416 pair rows and individual source energies/spans; `paired_summary.csv`
retains every median and fifth/95th percentile. Figure 2 intentionally omits
percentile clutter without deleting those quantities from the artefact.

## Inherited reference evidence

- FP16 all-15 energy: `data/robustness_20261009/fp16_energy_selection.csv`.
- FP16 all-15 matched spectral coverage: `fp16_psd_selection.json` in that directory.
- Scope processing configuration: `scopes_run_settings.json` there.
- Static calibration points and source workbook: `data/validation/calibration/`.
- Transformations and voltage-model evidence: `data/provenance/transformations/`.
- Fixed interior-window controls: `data/validation/controlled/fixed-window/`.
- Full prior method detail and execution configuration: `provenance/`.

The 79 inherited data files preserve their original content, including names
such as `historical` in input identities. Those are source locators, not a
chronological narrative in the main text. The full earlier PARMA package also
contains intermediate arrays and other unused outputs; this curated TIM
package does not duplicate those unused binary collections.

## Reference identities

The companion PARMA author manuscript is v0.15.1, with manuscript/evidence in
repository commit `85eb488587a51659239c45d966f930f7c7b72a6e`. It is not described
as an accepted or published proceedings article. The pause file was retrieved
from the same fixed commit through the GitHub connector and checked against
its Git blob identity. The supplied TIM source and PARMA source ZIP identities
are recorded in `metadata/SOURCE_INPUTS.json`. This new TIM manuscript has not
been uploaded to that commit or released online by this revision process.
