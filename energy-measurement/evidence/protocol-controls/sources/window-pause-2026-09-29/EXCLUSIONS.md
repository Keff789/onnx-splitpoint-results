# Publication boundary

The repository is public. This freeze follows its compact, curated-results convention.

Excluded from public Git: credentials, private keys, private network endpoints,
account-specific home paths, device UUIDs, shell history, operational screenshots,
models/engines, binaries, caches, raw ADC/NPY/Parquet arrays and complete private
knowledgebase/review ZIPs. Sources S01–S16 are instead preserved byte-for-byte in a
separate private companion bundle, with checksums. Do not upload that bundle publicly.

CSV files select explicitly identified fields without modifying numerical values.
Log excerpts contain selected complete lines, original line numbers and full-member
SHA-256. Code excerpts also retain source line numbers and original member hashes.
They are not represented as complete copies of the original files.

Full telemetry and power-bin series, detailed original logs, scripts and figures
remain in S01–S16. This public table freeze is not a replacement for those archives.
Source hashes alone do not make the originals recoverable and are not a backup.
